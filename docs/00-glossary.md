# Glossary

**ALB** - Application Load Balancer, AWS's HTTP/HTTPS load balancer.    
**ArgoCD** - a tool that automatically deploys Kubernetes applications when code changes are pushed to Git.    
**AZ** - Availability Zone, a physically separate data center within a cloud region.    
**CapEx** - Capital Expenditure, upfront spending on hardware or infrastructure you own.    
**CI/CD** - Continuous Integration / Continuous Deployment, automated pipeline for building, testing and deploying code.    
**CNI** - Container Network Interface, the plugin that handles networking between pods in Kubernetes.    
**ECR** - Elastic Container Registry, AWS's private container image registry.  
**EKS** - Elastic Kubernetes Service, AWS's managed Kubernetes offering.    
**GKE** - Google Kubernetes Engine, GCP's managed Kubernetes offering.  
**HA** - High Availability, a setup designed to keep services running even if one component fails.  
**HPA** - Horizontal Pod Autoscaler, automatically adjusts the number of running pods based on load.  
**IaaS** - Infrastructure as a Service, cloud provider gives you raw compute, storage and networking.  
**IAM** - Identity and Access Management, controls who or what can access cloud resources and what they can do.  
**Ingress** - a Kubernetes resource that routes external HTTP/HTTPS traffic to services inside the cluster.  
**JWT** - JSON Web Token, a signed token used to verify a user's identity between requests.  
**K8s** - shorthand for Kubernetes.  
**Kubernetes** - an open-source system for managing containerized applications across a cluster of machines.  
**Loki** - a log aggregation tool by Grafana Labs, stores and indexes logs from all containers.  
**NAT Gateway** - allows resources in private subnets to reach the internet without being publicly accessible themselves.  
**Node** - a virtual machine that runs inside a Kubernetes cluster and hosts pods.  
**Node group / Node pool** - a group of nodes in a Kubernetes cluster that share the same instance type and configuration.  
**OpEx** - Operational Expenditure, ongoing monthly spending, as opposed to owning hardware outright.  
**PaaS** - Platform as a Service, cloud provider manages the infrastructure and runtime, you just deploy code (e.g. Cloud Run, AWS Elastic Beanstalk).  
**PITR** - Point-in-Time Recovery, ability to restore a database to any specific moment within the backup window.  
**Pod** - the smallest deployable unit in Kubernetes, one or more containers running together.  
**Prometheus** - a monitoring tool that scrapes and stores metrics from applications and infrastructure.  
**Promtail** - an agent that collects container logs and forwards them to Loki.  
**RBAC** - Role-Based Access Control, restricts what users or services can do based on assigned roles.  
**RDS** - Relational Database Service, AWS's managed database offering.  
**Reserved Instance** - AWS pricing model where you commit to a specific instance for 1 or 3 years in exchange for a discount.  
**SaaS** - Software as a Service, fully managed software accessed via browser or API, no infrastructure to manage.  
**Spot / Preemptible** - spare cloud capacity sold at a large discount, can be interrupted with short notice.  
**TLS** - Transport Layer Security, the protocol behind HTTPS that encrypts traffic in transit.  
**VPC** - Virtual Private Cloud, an isolated private network within a cloud provider where you control IP ranges and access rules.  
**VPN** - Virtual Private Network, an encrypted tunnel used here to access private cloud services without exposing them to the internet.  
**WireGuard** - a lightweight open-source VPN protocol.
